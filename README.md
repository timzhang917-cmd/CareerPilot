# CareerPilot

---

## 1. Project Overview

CareerPilot is an AI-powered career support platform developed for job seekers and HR users. It provides structured CV–job matching analysis and integrates CV parsing, job searching, job posting, and application record management within a Django web application.

---

## 2. Main Features

- User registration, login, logout, and role-based access
- PDF and DOCX CV upload and text extraction
- CV analysis using DeepSeek or OpenAI
- Structured analysis results, including scores, strengths, gaps, job-requirement comparison,must-fix issues, and advanced suggestions
- Analysis history
- Job searching and filtering
- Personal job application management
- HR job posting and management

---

## 3. Project Structure

```text
careerpilot/
├── accounts/
├── analyses/
├── careerpilot/
├── jobs/
├── resumes/
├── media/
├── staticfiles/
├── manage.py
├── requirements.txt
├── db.sqlite3
└── .env
```

- `accounts/` – Handles user registration, login, logout, user roles, and HR access control.
- `analyses/` – Contains the core CV analysis workflow, model API calls, prompts, structured results, and analysis history.
- `careerpilot/` – Contains the main Django settings, root URL configuration, and deployment entry
- `jobs/` – Handles job searching, filtering, application records, and HR job posting.
- `resumes/` – Stores CV and job description data and extracts text from PDF and DOCX files.
- `media/` – Stores CV files uploaded by users.
- `staticfiles/` – Contains static files collected for deployment.
- `manage.py` – Provides Django management commands for running and maintaining the project.
- `requirements.txt` – Lists the dependencies required by the project.
- `db.sqlite3` – Stores the local SQLite database.
- `.env` – Stores private environment variables and API keys

## 4. Main Modules and AI Assistance

### Accounts

The author designed and implemented the user registration, login, logout, role-based redirection and access-control workflows. AI was used to help identify Django authentication components and import paths and to assist with parts of the HR group logic, role icons, accessible form structure and error presentation.

### Resumes

The author implemented the data models and CV text-extraction workflow using pypdf and python-docx. This module stores uploaded CVs and job descriptions and extracts text from PDF and DOCX files. No major part of this module was generated by AI.

### Analysis

The author designed and implemented the CV-analysis workflow, prompt framework, scoring criteria, model configuration, analysis history and structured result content. AI assisted with refactoring the main views, establishing the basic model-calling function structure, validating uploaded files, implementing selected templates and styles, and resolving the loading pop-up problem.

### Jobs

The author designed the job-search, job-posting and application-management workflows, together with the page structure and displayed content. AI assisted with separator handling, parts of the record editing, deletion and ownership-validation logic, dynamic filtering and rendering, modal interactions, forms, tables and responsive styles.

The overall requirements, architecture, database design, business logic, visual style and testing were controlled by the author. No module was produced entirely by AI. AI-assisted code is identified through AI usage declarations included as comments at the beginning of the relevant files. All AI-assisted code was reviewed, understood and tested by the author.
