# PDF report font

CareerPilot Report Sans is a static, regular-weight derivative of
[Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc).
The source file was `NotoSansSC[wght].ttf`, with SHA-256
`a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da`.
The `wght` axis was fixed at 400 and the font was renamed for redistribution.
The original glyph coverage is retained. See [OFL.txt](OFL.txt) for the license.
